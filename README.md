## 🎨 Photos & Text Customize Kaise Karein (2 Minutes Guide)

Sabhi details **`config.js`** file me hain. Is file ko kisi bhi text editor (VS Code, Sublime, Notepad) me open karo:

1. **Real Photos Dalna**:
   - Agar Taniksh ke paas Anokhee ke saath real photos hain:
   - Photos ko `assets/images/` folder me save kar do (e.g. `photo1.jpg`, `photo2.jpg`, etc.).
   - `config.js` me `memories` array me `image` path change karke `"assets/images/photo1.jpg"` kar do!
2. **Love Letter Edit Karna**:
   - `config.js` me `letter` section me jaakar jo bhi dil ki baat likhni ho Hindi ya English me likh sakte ho.
3. **Reasons / Inside Jokes**:
   - `config.js` me `reasons` list me apne personal moments aur inside jokes add kar sakte ho!
4. **Apna Favorite Song Dalna**:
   - Koi bhi MP3 song (jaise "Tum Se Hi", "Kesariya", "Perfect") ko `assets/audio/music.mp3` naam se save kar do, website wahi play karegi!

Taniksh chahe toh raat 12 baje Anokhee ko ek clickable link bhej sakta hai:

   - `npx vercel` chalao ya GitHub par push karke Vercel se 1-click deploy kar lo.

3. **GitHub Pages**:
   - GitHub repo banakar Settings > Pages me jaakar "Deploy from main branch" select karo.
