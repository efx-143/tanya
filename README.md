## 🚀 How to Run & Preview (Abhi Ke Abhi Kaise Dekhein)

### Option 1: Direct Double Click (Sabse Simple)
Apne file manager me `/home/sanyam/Desktop/taniksh/` folder me jao aur `index.html` par double click karo! Yeh direct Google Chrome ya kisi bhi browser me open ho jayega.

### Option 2: Local Python Server (Recommended)
Terminal me yeh command run karo:
```bash
cd /home/sanyam/Desktop/taniksh
python3 -m http.server 3000
```
Phir browser me open karo: `http://localhost:3000`
